# Лабораторная работа №3

**Системы искусственного интеллекта. Нечеткие системы логического вывода.**

Предметная область — охлаждение компьютера, связанное с диагностикой из работ №1 и №2.
Скорость вентилятора рассчитывается сначала по температуре процессора, затем по
температуре, загрузке и запылённости радиатора. Параметры являются учебными
экспертными оценками, программа не управляет оборудованием.

## Запуск

Python 3.10 или новее. Для программы и тестов сторонние пакеты не нужны.

Из корня репозитория:

```bash
python3 main.py
```

В PyCharm откройте `main.py` и нажмите Run. Путь к базам определяется по
расположению программы, поэтому текущая рабочая папка не влияет на запуск.
Enter в запросе параметра выбирает пример или первый оператор из списка.
Для десятичных чисел в меню можно использовать точку или запятую.

## Что реализовано

- Одна входная и одна выходная переменные, **7 правил**.
- Три входные и одна выходная переменные, **27 правил**, все сочетания термов.
- Два композиционных механизма: **max-min**, **max-product**.
- Вывод по **уровням истинности предпосылок** для одной и нескольких переменных.
- Импликации/операции следствия: **Мамдани, Ларсена, Клини — Динеса, Лукасевича**.
- Агрегация результатов правил: **max, min, probor, bounded_sum**.
- Оператор И в предпосылке: **min** или **product**.
- Треугольные и трапециевидные нечеткие множества; чёткие и нечеткие наблюдения.
- Дефаззификация методом центра тяжести, трассировка степеней принадлежности,
  уровней истинности всех правил и предупреждения о вырожденном выходе.

## Базы знаний

Оба файла `.txt` являются обычными текстовыми файлами UTF-8 в формате JSON.
В них хранятся диапазоны, шаги сеток, термы с параметрами функций принадлежности,
правила и исходные примеры. Для изменения модели достаточно отредактировать файл
и снова запустить расчёт. Загрузчик проверяет ссылки на термы и диапазоны.

Пример терма и правила:

```json
{"type": "triangle", "params": [65, 80, 95]}
```

```json
{"if": [["temperature", "повышенная"]], "then": "высокая"}
```

`triangle(a,b,c)` задаёт треугольник, `trapezoid(a,b,c,d)` — трапецию.
Совпавшие крайние параметры задают плечо: `triangle(20,20,35)` имеет
принадлежность 1 при 20 и 0 при 35. Условия в одном правиле соединяются через И.
Выход в `then` относится к единственной выходной переменной базы.

## Как различаются механизмы

Композиционные механизмы сначала строят отношение
`R(x,y) = Agg_i I(A_i(x),B_i(y))`, затем выполняют
`max_x min(A'(x),R(x,y))` или `max_x A'(x)*R(x,y)`.
Агрегация выполняется **до** композиции (FATI).

Для точного входа `A'` — синглтон в введённой точке. Поэтому обе композиции
совпадают с выводом по уровням истинности: это ожидаемое свойство.
Для нечеткого входа механизмы могут дать различные выходные множества.
При Мамдани и max композиция max-min также эквивалентна выводу по
совместимости `alpha_i = max_x min(A'(x),A_i(x))`.
Нечеткость наблюдения и фаззификация точного числа — разные операции.

Для трёх входов используются уровни истинности; полное декартово отношение
не строится. Общий программный интерфейс `infer` поддерживает любое число входов.

## Интерпретация сравнения

Мамдани и Ларсен — традиционные операции формирования следствия в системах
управления; они не удовлетворяют всем аксиомам логической импликации.
У Клини — Динеса и Лукасевича `I(0,b)=1`. Поэтому при max нулевое правило
может заполнить весь выход единицами. Программа учитывает **все** правила и
показывает этот эффект: 55 % является центром постоянного множества на [10,100].
Такой результат не следует принимать за содержательную рекомендацию модели.

Для этих логических импликаций отдельно приведена агрегация min, соответствующая
совместному выполнению ограничений. Напротив, Мамдани и Ларсен с min дают пустое
множество из-за нулевых правил. Его центр тяжести не определён; программа не
подменяет отсутствие результата нулём. Значения min и max сравниваются с явным
указанием оператора.

## Численная точность и проверка

Интегрирование площади и первого момента выполняется точно для линейной
интерполяции дискретного выхода. Шаги задаются в базах: 0.25 °C для температуры,
0.25 % для выхода, 0.05 балла для пыли. В сетки добавляются вершины функций и
пересечения входного наблюдения с термами. Точка точного входа учитывается
без округления к сетке. Нелинейные операции и композиция остаются численными.
Шесть знаков в CSV отражают вычисленный результат, а не физическую точность модели.

15 тестов проверяют аналитические примеры, формулы, обе композиции, совпадение
механизмов для синглтона, трёхвходные правила, 27 опорных сочетаний,
логические импликации, пустое множество, ошибочные данные и сгущение сетки.
